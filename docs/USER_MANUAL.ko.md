## 1. 소개

TVClock Modern은 Windows 데스크톱에 상시 표시할 수 있는 디지털 시계입니다.
항상 맨 앞·테두리 없음·배경 투명 창으로 동작하며, 외관과 동작을 세밀하게 사용자 지정할 수 있습니다.

### 동작 환경

| 항목 | 요구 사항 |
|---|---|
| OS | Windows 10 / 11 (x64) |
| 런타임 | .NET 8 Desktop Runtime(자체 완결형 exe에는 불필요) |

### 제한 사항

- 본 소프트웨어는 **현상 그대로(AS IS) 제공되며, 어떠한 보증도 없습니다**(자세한 내용은 README의 면책 조항 참조)
- 다중 동시 실행은 불가능합니다(두 번째 실행 시 메시지가 표시되고 종료됩니다)

## 2. 설치 및 실행

### 설치

설치 프로그램은 없습니다. 배포된 `TVClockModern.exe`를 원하는 폴더에 놓기만 하면 사용할 수 있습니다.
(레지스트리는 "자동 시작"을 활성화한 경우에만 수정합니다.)

### 실행

- exe를 더블클릭하면 시계가 데스크톱에 표시되고 작업 표시줄 트레이에 상주합니다
- 위치·설정은 자동으로 저장되며 다음 실행 시 복원됩니다

### 종료

- 시계를 **마우스 오른쪽 버튼 → 종료**
- 또는 작업 표시줄 트레이 아이콘 → **종료**

### Windows 시작 시 자동 실행

설정 → 동작 탭 → **"Windows 시작 시 자동 실행"**을 체크하고 적용합니다.
(레지스트리 `HKCU\...\Run`에 등록합니다. 해제는 체크를 끄고 적용하면 됩니다.)

## 3. 기본 조작

| 조작 | 동작 |
|---|---|
| 시계 드래그 | 이동(위치는 즉시 저장) |
| 시계 더블클릭 | 설정 화면 열기 |
| 시계 오른쪽 클릭 | 메뉴(설정 / 항상 맨 앞 / 클릭 통과 / 종료) |
| 작업 표시줄 트레이 더블클릭 | 설정 화면 열기 |
| 작업 표시줄 트레이 오른쪽 클릭 | 전체 메뉴 |

### 클릭 통과 상태에서의 조작

"클릭 통과"를 활성화하면 시계 영역을 클릭할 수 없게 됩니다(아래 화면을 조작할 수 있습니다).
이 경우 **작업 표시줄 트레이 아이콘에서 모든 조작이 가능합니다**.

또한 **투명 해제 키(기본값: Ctrl)를 누르고 있는 동안**에는:

- 시계가 완전 표시되어 클릭할 수 있게 됩니다
- 오른쪽 클릭으로 메뉴를 열 수 있습니다
- 키를 떼면 원래 상태(반투명 + 클릭 통과)로 돌아갑니다

### 여러 모니터 표시

"모든 모니터에 동시 표시"를 활성화하면 모니터마다 시계가 하나씩 표시됩니다.
이 경우에도 조작 방법은 동일합니다(설정은 모든 시계에서 공유).

## 4. 설정 참조(서식/문자/장식 탭)

### 시간 서식

시간 서식을 자유롭게 지정할 수 있습니다. 주요 예:

| 서식 | 표시 예 |
|---|---|
| `HH:mm` | 09:05 |
| `HH:mm:ss` | 09:05:33 |
| `h:mm` | 9:05(앞자리 0 없음) |
| `hh:mm tt` | 09:05 오전 |
| `H時m分` | 9時5分 |

서식 지정자에 대한 자세한 내용은 [6. 날짜·시간 서식 지정자](#6-날짜시간-서식-지정자)를 참조하세요.

### 날짜 서식 / 날짜 표시

- 비워 두거나 "날짜 표시"를 끄면 숨겨집니다
- 예: `yyyy/MM/dd (ddd)` → `2026/10/15 (목)`

### 글꼴 / 글꼴 크기

시스템에 설치된 글꼴에서 선택합니다. 크기는 12~200입니다.

### 문자 색

색 선택 대화상자에서 지정합니다.

### 문자 간격 / 구분자 간격

- **문자 간격**: 숫자 사이의 간격(0~50)
- **구분자 간격**: ":" 등 구분 문자 앞뒤의 여백(0~200)
- 고정폭 글꼴 + 문자 간격 0이 가장 컴팩트합니다

### 시간 전환 효과 / 효과 시간

초·분이 바뀌는 순간의 애니메이션입니다.

| 효과 | 움직임 |
|---|---|
| 없음 | 즉시 전환 |
| 가로 회전 | 기존 숫자가 세로축으로 눌리고 새 숫자가 펼쳐짐 |
| 세로 회전 | 가로축 기준 반전 |
| 위로 슬라이드 | 기존 숫자가 위로 빠지고 아래에서 올라옴(슬롯식) |
| 아래로 슬라이드 | 반대 방향의 슬롯식 |
| 페이드 인·아웃 | 사라진 뒤 나타남 |
| 크로스 페이드 | 겹치면서 교차 |

효과 시간은 50~500ms입니다. 길수록 화려하고, 짧을수록 경쾌합니다.

### 문자 외곽선

문자 주위에 지정한 색의 테두리를 추가합니다(배경화면이 밝은 경우 가독성 향상에 효과적).
색과 굵기(0.5~10)를 지정할 수 있습니다.

### 그림자

문자에 그림자를 추가합니다. 크기(블러 반경 0~40)와 농도(0~1)를 지정합니다.

### 창 불투명도(일반 시)

시계 전체의 불투명도입니다. 0.2~1.0.
"마우스 접근 페이드"를 사용하는 경우 **마우스가 떨어져 있을 때의 농도**이기도 합니다.

(동작 탭의 "마우스 접근 시" 섹션에 있습니다.)

## 5. 설정 참조(동작 탭)

### 표시할 모니터

- **자동(현재 위치)**: 저장된 위치에 표시(기존 동작)
- **특정 모니터**: 선택한 모니터의 작업 영역(작업 표시줄 제외)에 배치

### 모든 모니터에 동시 표시

켜면 **모니터마다 시계가 하나씩** 표시됩니다.

- 각 시계의 위치는 모니터별로 기억됩니다
- 모니터의 증감·연결 해제에 자동으로 따라갑니다
- "표시할 모니터" 지정은 무시됩니다

### 항상 맨 앞에 표시

끄면 다른 창 뒤에 가려질 수 있습니다.

### 클릭 통과 / 투명 해제 키

- 클릭 통과: 시계 영역의 마우스 조작을 아래 화면으로 통과시킵니다
- 투명 해제 키(Ctrl / Alt / Shift / 없음)를 누르고 있는 동안:
  - 클릭 통과가 일시 해제되어 시계를 클릭할 수 있습니다
  - 반투명이 취소되고 완전 표시됩니다
  - 오른쪽 클릭 메뉴도 열 수 있습니다

### Windows 시작 시 자동 실행

앞서 설명한 대로입니다. 현재 exe의 경로를 레지스트리에 등록합니다.
**exe를 이동한 경우에는 다시 체크하고 적용하세요.**

### 마우스 접근 시

| 항목 | 설명 |
|---|---|
| 활성화 | 체크 시 기능 켜짐 |
| 감지 거리(px) | 커서가 이 거리 이내로 오면 반응(10~400) |
| 접근 시 불투명도 | 접근 중의 농도(0.1이면 거의 투명) |
| 반응 속도 | 1(느림, 1초)~10(빠름, 30ms) |
| 페이드 커브 | 선형 / 감속 / 가속 |

- **투명 해제 키를 누르고 있는 동안에는 접근 시 설정보다 우선하여 완전 표시**됩니다
- 접근 판정은 초당 60회 폴링으로, CPU에 미치는 영향은 극히 적습니다

## 6. 날짜·시간 서식 지정자

자주 사용하는 지정자 목록입니다(.NET 표준 서식).

### 시간

| 지정자 | 의미 | 예(2026-10-15 21:05:09) |
|---|---|---|
| `HH` | 시(24시간제, 2자리) | 21 |
| `H` | 시(24시간제, 앞자리 0 생략) | 21 |
| `hh` | 시(12시간제, 2자리) | 09 |
| `h` | 시(12시간제, 앞자리 0 생략) | 9 |
| `mm` | 분(2자리) | 05 |
| `ss` | 초(2자리) | 09 |
| `tt` | 오전/오후 | 오후 |

### 날짜

| 지정자 | 의미 | 예 |
|---|---|---|
| `yyyy` | 연도(4자리) | 2026 |
| `yy` | 연도(2자리) | 26 |
| `MM` | 월(2자리) | 10 |
| `M` | 월(앞자리 0 생략) | 10 |
| `dd` | 일(2자리) | 15 |
| `ddd` | 요일(약어) | 목 |
| `dddd` | 요일(전체) | 목요일 |

### 조합 예

| 서식 | 표시 예 |
|---|---|
| `yyyy年M月d日(ddd)` | 2026年10月15日(목) |
| `M/d ddd` | 10/15 목 |
| `yyyy-MM-dd` | 2026-10-15 |
| `HH:mm:ss` | 21:05:09 |

## 7. 멀티 모니터와 표시 위치

### 위치 저장 방식

- 시계의 위치는 **모니터 작업 영역 왼쪽 위를 기준으로 한 상대 위치**로 저장됩니다
- 따라서 모니터 해상도 변경이나 재배열이 있어도 상대적인 위치 관계가 유지됩니다
- 드래그 종료 시 즉시 저장되고, 추가로 매분 자동 저장됩니다(강제 종료되어도 기본적으로 복원됩니다)

### 위치 프리셋

설정 → 동작 탭의 **왼쪽 위 / 오른쪽 위 / 왼쪽 아래 / 오른쪽 아래 / 가운데** 버튼으로 즉시 정렬합니다.

- 각 시계는 **각자 표시 중인 모니터**를 기준으로 움직입니다
- 프리셋 사용 후에는 자릿수 변화로 크기가 바뀌어도 **벗어나지 않도록 자동 재정렬**됩니다
- 프리셋을 사용하지 않고 드래그한 경우에는 드래그한 위치가 우선됩니다

### 모니터 연결·해제 시

- 모니터가 해제되면 그 위의 시계는 보이는 위치로 자동 대피합니다
- 다시 연결되면 기억한 위치로 자동 복귀합니다
- "모든 모니터에 동시 표시"가 활성화된 경우, 모니터 증감에 맞춰 시계가 자동으로 증감합니다

## 8. 설정 백업

설정 화면 하단의 "설정 이동"에서:

- **내보내기**: 현재 설정을 JSON 파일로 저장합니다(다른 PC로 옮길 때)
- **가져오기**: JSON 파일에서 설정을 읽어들여 즉시 반영합니다

내보낸 파일은 텍스트 편집기로 편집할 수도 있습니다(손상된 경우 가져오기 시 기본값으로 폴백합니다).

---

## 9. 설정 초기화

1. TVClock Modern을 종료합니다
2. 다음 폴더의 `settings.json`을 삭제(또는 이름 변경)합니다
   ```
   %APPDATA%\TVClockModern\settings.json
   ```
3. 다시 실행하면 기본값으로 시작합니다

> 설정 파일이 손상된 경우 자동으로 백업(`settings.bak`)에서 복원되며,
> 그것도 불가능하면 기본값으로 시작합니다. 손상된 파일은 `settings.json.corrupt-<날짜시간>`으로 남습니다.

## 10. 문제 해결

### 시계가 화면에서 사라진 경우

- 모니터 구성을 변경한 직후에는 자동 보정이 작동합니다. 몇 초 기다리거나 설정 화면(작업 표시줄 트레이에서)을 열고 "적용"을 누르세요
- "표시할 모니터"를 지정한 경우에는 해당 모니터의 중앙으로 자동 이동합니다

### 클릭할 수 없는 경우(클릭 통과 중)

- 작업 표시줄 트레이 아이콘 → "클릭 통과" 체크 해제
- 또는 **Ctrl을 누른 채로** 조작(투명 해제 키)

### 이중 실행이 안 되는 경우

- 사양입니다. 이미 실행 중이면 메시지를 표시하고 종료합니다

### 위치·설정이 원래대로 돌아가는 경우

- `%APPDATA%\TVClockModern\settings.json`이 올바르게 저장되어 있는지 확인하세요
- exe를 이동한 경우 "Windows 시작 시 자동 실행"을 다시 설정하세요

### 글꼴이 적용되지 않거나 문자가 깨지는 경우

- 글꼴 이름이 정확히 일치하는지 확인하세요(복사·붙여넣기 권장)

### 로그 확인

```
%LOCALAPPDATA%\TVClockModern\logs\app-YYYYMMDD.log
```

로그는 7일치가 보관됩니다. 버그 보고 시 이 파일을 첨부해 주세요.
