## 1. はじめに

TVClock Modern は、Windows のデスクトップ上に常時表示できるデジタル時計です。
常に手前・枠なし・背景透明のウィンドウとして動作し、見た目や動作を細かくカスタマイズできます。

### 動作環境

| 項目 | 要件 |
|---|---|
| OS | Windows 10 / 11 (x64) |
| ランタイム | .NET 8 Desktop Runtime(自己完結版 exe の場合は不要) |

### 制限事項

- 本ソフトウェアは**現状有姿(AS IS)で提供され、いかなる保証もありません**(詳細は README の免責事項)
- 複数同時起動はできません(2つ目を起動するとメッセージが表示され終了します)

---

## 2. インストールと起動

### インストール

インストーラーはありません。配布された `TVClockModern.exe` を任意のフォルダに置くだけで使用できます。
(レジストリは「自動起動」を有効にしたときのみ書き換えます)

### 起動

- exe をダブルクリックすると、時計がデスクトップに表示され、タスクトレイに常駐します
- 位置・設定は自動的に保存され、次回起動時に復元されます

### 終了

- 時計を**右クリック → 終了**
- またはタスクトレイアイコン → **終了**

### Windows 起動時に自動で開始

設定 → 動作タブ → **「Windows 起動時に自動で開始」**をチェックして適用。
(レジスタ `HKCU\...\Run` に登録します。解除はチェックを外して適用)

## 3. 基本操作

| 操作 | 動作 |
|---|---|
| 時計をドラッグ | 移動(位置は即座に保存) |
| 時計をダブルクリック | 設定画面を開く |
| 時計を右クリック | メニュー(設定 / 常に手前 / クリックスルー / 終了) |
| タスクトレイをダブルクリック | 設定画面を開く |
| タスクトレイを右クリック | 全メニュー |

### クリックスルー時の操作

「クリックスルー」を有効にすると、時計の領域がクリックできなくなります(下の画面を操作できます)。
その場合は **タスクトレイのアイコンからすべての操作が可能**です。

また、**透明解除キー(既定: Ctrl)を押している間**は:

- 時計が完全表示になり、クリックできるようになります
- 右クリックでメニューが出せます
- キーを離すと元の状態(半透明+クリックスルー)に戻ります

### 複数モニタ表示

「すべてのモニターに同時表示」を有効にすると、モニタごとに時計が1つずつ表示されます。
この場合も操作方法は同じです(設定はすべての時計で共有)。

## 4. 設定リファレンス(表示タブ)

### 時刻フォーマット

時刻の書式を自由に指定できます。主な例:

| 書式 | 表示例 |
|---|---|
| `HH:mm` | 09:05 |
| `HH:mm:ss` | 09:05:33 |
| `h:mm` | 9:05(先頭の 0 なし) |
| `hh:mm tt` | 09:05 午前 |
| `H時m分` | 9時5分 |

書式指定子の詳細は [6. 日付・時刻の書式指定子](#6-日付時刻の書式指定子) を参照。

### 日付フォーマット / 日付を表示

- 空欄または「日付を表示」オフで非表示
- 例: `yyyy/MM/dd (ddd)` → `2026/10/15 (木)`

### フォント / フォント サイズ

システムにインストールされているフォントから選択。サイズは 12〜200。

### 文字の色

色選択ダイアログで指定します。

### 文字間隔 / 区切り間隔

- **文字間隔**: 数字同士の隙間(0〜50)
- **区切り間隔**: 「:」など区切り文字の前後の余白(0〜200)
- 等幅フォント + 文字間隔 0 が最もコンパクトです

### 時刻の切り替え効果 / 効果時間

秒・分が切り替わる瞬間のアニメーション。

| 効果 | 動き |
|---|---|
| なし | 即時切替 |
| 横に回転 | 古い数字が縦軸で潰れ、新しい数字が展開 |
| 縦に回転 | 横軸での反転 |
| せり上げ | 古い数字が上へ抜け、下からせり上がる(スロット式) |
| せり下げ | 逆方向のスロット |
| フェードイン・アウト | 消えてから出る |
| クロスフェード | 重なりながら交差 |

効果時間は 50〜500ms。長いほど派手ですが、短いほど軽快です。

### 文字の縁取り

文字の周囲に指定色の縁を付けます(壁紙が明るい場合の視認性向上に有効)。
色と太さ(0.5〜10)を指定できます。

### 影

文字に影を付けます。大きさ(ぼかし半径 0〜40)と濃さ(0〜1)を指定。

### ウィンドウの不透明度(通常時)

時計全体の不透明度。0.2〜1.0。
「マウス接近フェード」を使用する場合の、**マウスが離れているときの濃さ**でもあります。

## 5. 設定リファレンス(動作タブ)

### 表示するモニター

- **自動 (現在の位置)**: 保存された位置に表示(従来動作)
- **特定のモニタ**: 選択したモニタの作業領域(タスクバー除く)に配置

### すべてのモニターに同時表示

オンにすると**モニタごとに時計が1つずつ**表示されます。

- 各時計の位置はモニタごとに記憶されます
- モニタの増減・接続解除に自動追従します
- 「表示するモニター」の指定は無視されます

### 常に手前に表示

オフにすると他のウィンドウの下に隠れます。

### クリックスルー / 透明解除キー

- クリックスルー: 時計の領域でマウス操作を下の画面に通します
- 透明解除キー(Ctrl / Alt / Shift / なし)を押している間は:
  - クリックスルーが一時解除され、時計をクリックできます
  - 半透明がキャンセルされ、完全表示になります
  - 右クリックメニューも出せます

### Windows 起動時に自動で開始

前述のとおり。レジスタに現在の exe のパスを登録します。
**exe を移動した場合は再度チェックを入れて適用してください。**

### マウスが近づいたとき

| 項目 | 説明 |
|---|---|
| 有効 | チェックで機能オン |
| 感度 (距離 px) | カーソルがこの距離以内に来ると反応(10〜400) |
| 接近時の不透明度 | 接近中の濃さ(0.1 でほぼ透明) |
| 反応速度 | 1(ゆっくり 1秒)〜10(速い 30ms) |
| フェードカーブ | リニア / 減速 / 加速 |

- **透明解除キーを押している間は接近時の設定より優先して完全表示**になります
- 接近判定は毎秒 60 回のポーリングで、CPU への影響はごくわずかです

## 6. 日付・時刻の書式指定子

よく使う指定子の一覧です(.NET 標準書式)。

### 時刻

| 指定子 | 意味 | 例(2026-10-15 21:05:09) |
|---|---|---|
| `HH` | 時(24時間・2桁) | 21 |
| `H` | 時(24時間・1桁省略) | 21 |
| `hh` | 時(12時間・2桁) | 09 |
| `h` | 時(12時間・1桁省略) | 9 |
| `mm` | 分(2桁) | 05 |
| `ss` | 秒(2桁) | 09 |
| `tt` | 午前/午後 | 午後 |

### 日付

| 指定子 | 意味 | 例 |
|---|---|---|
| `yyyy` | 年(4桁) | 2026 |
| `yy` | 年(2桁) | 26 |
| `MM` | 月(2桁) | 10 |
| `M` | 月(1桁省略) | 10 |
| `dd` | 日(2桁) | 15 |
| `ddd` | 曜日(省略形) | 木 |
| `dddd` | 曜日(完全) | 木曜日 |

### 組み合わせの例

| 書式 | 表示例 |
|---|---|
| `yyyy年M月d日(ddd)` | 2026年10月15日(木) |
| `M/d ddd` | 10/15 木 |
| `yyyy-MM-dd` | 2026-10-15 |
| `HH:mm:ss` | 21:05:09 |

## 7. マルチモニタと表示位置

### 位置の記憶方法

- 時計の位置は**モニタの作業領域の左上からの相対位置**として記憶されます
- そのため、モニタの解像度変更や並び替えがあっても、相対的な位置関係が維持されます
- ドラッグ終了時に即保存、さらに毎分自動保存されます(強制終了されても基本的に復元されます)

### 位置プリセット

設定 → 動作タブの **左上 / 右上 / 左下 / 右下 / 中央** ボタンで即座に整列します。

- 各時計は**それぞれが表示されているモニタ**を基準に動きます
- プリセット使用後は、桁数変化でサイズが変わっても**はみ出さないよう自動再整列**されます
- プリセットを使わずドラッグした場合は、ドラッグ位置が優先されます

### モニタの接続・切断時

- モニタが切断されると、その上の時計は見える位置へ自動的に退避します
- 再接続すると、記憶した位置へ自動復帰します
- 「すべてのモニターに同時表示」が有効な場合、モニタの増減に合わせて時計が自動的に増減します

## 8. 設定のバックアップ

設定画面下部の「設定の移動」から:

- **エクスポート**: 現在の設定を JSON ファイルに保存します(他 PC への持ち運びに)
- **インポート**: JSON ファイルから設定を読み込み、即座に反映します

エクスポートしたファイルはテキストエディタで編集することもできます(壊れた場合はインポート時に既定値へフォールバックします)。

---

## 9. 設定の初期化

1. TVClock Modern を終了する
2. 以下のフォルダの `settings.json` を削除(またはリネーム)
   ```
   %APPDATA%\TVClockModern\settings.json
   ```
3. 再度起動すると既定値で起動します

> 設定ファイルが壊れていた場合は、自動的にバックアップ(`settings.bak`)から復元、
> それも不可なら既定値で起動します。破損ファイルは `settings.json.corrupt-日時` として残ります。

## 10. トラブルシューティング

### 時計が画面から消えた

- モニタ構成を変更した直後は自動補正が働きます。数秒待つか、設定画面(タスクトレイから)を開いて「適用」を押してください
- 「表示するモニター」を指定している場合は、そのモニタの中央へ自動移動します

### クリックできない(クリックスルー中)

- タスクトレイアイコン →「クリックスルー」のチェックを外す
- または **Ctrl を押しながら**操作(透明解除キー)

### 二重起動できない

- 仕様です。既に起動している場合はメッセージを表示して終了します

### 位置・設定が元に戻る

- `%APPDATA%\TVClockModern\settings.json` が正しく保存されているか確認してください
- exe を移動した場合は「Windows 起動時に自動で開始」を付け直してください

### フォントが反映されない / 文字化けする

- フォント名が正確に一致しているか確認してください(コピペ推奨)

### ログの確認

```
%LOCALAPPDATA%\TVClockModern\logs\app-YYYYMMDD.log
```

7日分のログが保持されます。バグ報告の際はこのファイルを添付してください。
