## 1. 简介

TVClock Modern 是一款可以常驻显示在 Windows 桌面上的数字时钟。
它以置顶、无边框、透明背景的窗口形式运行,外观和行为均可细致自定义。

### 运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11 (x64) |
| 运行时 | .NET 8 Desktop Runtime(自包含版 exe 无需) |

### 限制事项

- 本软件**按"现状"(AS IS)提供,不作任何保证**(详情见 README 中的免责声明)
- 不支持同时多开(启动第二个实例时会显示消息并退出)

## 2. 安装与启动

### 安装

没有安装程序。只需将分发的 `TVClockModern.exe` 放到任意文件夹即可使用。
(仅在启用"开机自动启动"时才会写入注册表。)

### 启动

- 双击 exe 后,时钟会显示在桌面上,并常驻任务栏托盘
- 位置和设置会自动保存,并在下次启动时恢复

### 退出

- 右键点击时钟 → **退出**
- 或从任务栏托盘图标 → **退出**

### 随 Windows 启动自动运行

设置 → 行为选项卡 → 勾选 **"随 Windows 启动自动运行"** 并应用。
(注册到注册表 `HKCU\...\Run`。取消勾选并应用即可解除。)

## 3. 基本操作

| 操作 | 效果 |
|---|---|
| 拖动时钟 | 移动(位置立即保存) |
| 双击时钟 | 打开设置画面 |
| 右键点击时钟 | 菜单(设置 / 总在最前 / 点击穿透 / 退出) |
| 双击任务栏托盘图标 | 打开设置画面 |
| 右键点击任务栏托盘图标 | 完整菜单 |

### 点击穿透状态下的操作

启用"点击穿透"后,时钟区域将无法点击(可操作其下方的画面)。
此时**所有操作均可通过任务栏托盘图标进行**。

此外,**按住透明解除键(默认:Ctrl)期间**:

- 时钟完全显示,变为可点击
- 可右键弹出菜单
- 松开按键后恢复原状态(半透明 + 点击穿透)

### 多显示器显示

启用"在所有显示器上同时显示"后,每个显示器各显示一个时钟。
此情况下操作方式相同(所有时钟共享设置)。

## 4. 设置参考(格式/文字/装饰选项卡)

### 时间格式

可自由指定时间格式。主要示例:

| 格式 | 显示示例 |
|---|---|
| `HH:mm` | 09:05 |
| `HH:mm:ss` | 09:05:33 |
| `h:mm` | 9:05(无前导零) |
| `hh:mm tt` | 09:05 上午 |
| `H時m分` | 9時5分 |

格式说明符的详情请参见 [6. 日期时间格式说明符](#6-日期时间格式说明符)。

### 日期格式 / 显示日期

- 留空或关闭"显示日期"即可隐藏日期
- 示例: `yyyy/MM/dd (ddd)` → `2026/10/15 (周四)`

### 字体 / 字体大小

从系统中已安装的字体中选择。大小范围为 12–200。

### 粗体

勾选后，时间和日期都以粗体显示。
部分字体不提供粗体（此时 WPF 会回退到最接近的字重）。


### 启动时检查更新

勾选后，应用启动时会查询 GitHub Releases 是否有新版本（最多每 24 小时一次）。
发现新版本时，任务栏托盘会显示通知，“信息”页签中也会显示。
点击通知或“信息”页签中的按钮可打开发布页面（下载）。不会自动下载。
离线启动时不会显示错误，只会静默跳过，也不会发送任何遥测数据。

### 语言

可选择界面（菜单和设置窗口）的语言：日本語 / English / 简体中文 / 한국어。
默认“自动（跟随系统）”会跟随 Windows 的显示语言。
更改会立即应用到所有窗口。日期和星期显示遵循 Windows 的区域设置。


### 鼠标接近时

| 项目 | 说明 |
|---|---|
| 启用 | 勾选后开启功能 |
| 灵敏度(距离 px) | 光标进入该距离内即触发(10–400) |
| 接近时不透明度 | 鼠标接近期间的浓度(0.1 为几乎透明) |
| 反应速度 | 1(慢,1 秒)– 10(快,30 ms) |
| 淡入曲线 | 线性 / 减速 / 加速 |

- **按住透明解除键期间,完全显示优先于接近时设置**
- 接近检测以每秒 60 次轮询进行,对 CPU 的影响极小

## 6. 日期时间格式说明符

常用说明符一览(.NET 标准格式)。

### 时间

| 说明符 | 含义 | 示例(2026-10-15 21:05:09) |
|---|---|---|
| `HH` | 小时(24 小时制,2 位) | 21 |
| `H` | 小时(24 小时制,省略前导零) | 21 |
| `hh` | 小时(12 小时制,2 位) | 09 |
| `h` | 小时(12 小时制,省略前导零) | 9 |
| `mm` | 分钟(2 位) | 05 |
| `ss` | 秒(2 位) | 09 |
| `tt` | 上午/下午 | 下午 |

### 日期

| 说明符 | 含义 | 示例 |
|---|---|---|
| `yyyy` | 年(4 位) | 2026 |
| `yy` | 年(2 位) | 26 |
| `MM` | 月(2 位) | 10 |
| `M` | 月(省略前导零) | 10 |
| `dd` | 日(2 位) | 15 |
| `ddd` | 星期(缩写) | 周四 |
| `dddd` | 星期(完整) | 星期四 |

### 组合示例

| 格式 | 显示示例 |
|---|---|
| `yyyy年M月d日(ddd)` | 2026年10月15日(周四) |
| `M/d ddd` | 10/15 周四 |
| `yyyy-MM-dd` | 2026-10-15 |
| `HH:mm:ss` | 21:05:09 |

## 7. 多显示器与显示位置

### 位置的保存方式

- 时钟位置以**相对于显示器工作区左上角的偏移量**保存
- 因此即使显示器分辨率改变或重新排列,相对位置关系也会保持
- 拖动结束时立即保存,且每分钟自动保存一次(即使被强制结束,通常也能恢复)

### 位置预设

通过设置 → 行为选项卡中的 **左上 / 右上 / 左下 / 右下 / 居中** 按钮立即对齐。

- 各时钟以**其所在显示器**为基准移动
- 使用预设后,即使因位数变化而改变大小,也会**自动重新对齐以避免超出**
- 不使用预设而拖动时,以拖动位置为准

### 显示器连接/断开时

- 显示器断开时,其上的时钟会自动移动到可见位置
- 重新连接后,自动返回记忆的位置
- 启用"在所有显示器上同时显示"时,时钟会随显示器增减自动增减

## 8. 设置备份

通过设置画面下方的"设置迁移":

- **导出**: 将当前设置保存为 JSON 文件(便于携带到其他电脑)
- **导入**: 从 JSON 文件读取设置并立即生效
导出/导入按钮位于设置窗口的“信息”页签。“信息”页签还会显示当前版本，并提供“检查更新”按钮（发现新版本时显示托盘通知）以及打开发布页面的按钮。

导出的文件也可用文本编辑器编辑(如损坏,导入时会回退到默认值)。

---

## 9. 重置设置

1. 退出 TVClock Modern
2. 删除(或重命名)以下文件夹中的 `settings.json`
   ```
   %APPDATA%\TVClockModern\settings.json
   ```
3. 再次启动时将以默认值启动

> 如果设置文件损坏,会自动从备份(`settings.bak`)恢复;
> 若也无法恢复,则以默认值启动。损坏的文件将以 `settings.json.corrupt-<日期时间>` 保留。

## 10. 故障排除

### 时钟从画面上消失

- 刚更改显示器配置后,自动修正会生效。等待几秒,或打开设置画面(从任务栏托盘)点击"应用"
- 如果指定了"显示的显示器",会自动移动到该显示器的中央

### 无法点击(点击穿透状态中)

- 任务栏托盘图标 → 取消勾选"点击穿透"
- 或**按住 Ctrl** 操作(透明解除键)

### 无法多开

- 这是设计如此。已在运行时会显示消息并退出

### 位置/设置被还原

- 请检查 `%APPDATA%\TVClockModern\settings.json` 是否正确保存
- 如果移动了 exe,请重新勾选"随 Windows 启动自动运行"

### 字体未生效 / 文字乱码

- 请检查字体名是否完全匹配(建议复制粘贴)

### 查看日志

```
%LOCALAPPDATA%\TVClockModern\logs\app-YYYYMMDD.log
```

日志保留 7 天。报告 Bug 时请附上此文件。
